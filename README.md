# Financial Analytics & Reporting Service — Курсовая работа

Приложение на Python для анализа финансовых транзакций, генерации бизнес-отчетов и веб-представлений данных. Проект реализует паттерн разделения логики на сервисы, отчетный блок и утилиты с полным покрытием unit-тестами.

## Архитектура проекта

- `src/views.py` — веб-представления и формирование JSON-ответов для дашбордов.
- `src/reports.py` — модули аналитических отчетов (траты по категориям, кешбэк, категории с наибольшими расходами).
- `src/services.py` — бизнес-логика (поиск транзакций, фильтрация по физ. лицам, категории и датам).
- `src/utils.py` — считывание данных из файлов (JSON, CSV, XLSX), конвертация валют через API и вспомогательный функционал.
- `src/main.py` — главная точка входа для сборки аналитического отчета.

## Функциональность

- **Загрузка и парсинг транзакций:** Поддержка работы с файлами Excel, CSV и JSON.
- **Генерация отчетов (Reports):** Расчет финансовой аналитики за определенные периоды времени.
- **Сервисный слой (Services):** Фильтрация транзакций, поиск по строкам и переводам.
- **Интеграция с внешними API:** Получение актуальных курсов валют и акций.
- **Тестирование:** Модульное тестирование всех слоев приложения (`reports`, `services`, `views`, `utils`).

## Технологический стек

- **Язык:** Python 3.10+
- **Управление зависимостями:** Poetry (`pyproject.toml`)
- **Обработка данных:** `pandas`, `openpyxl`
- **Тестирование:** `pytest`, `pytest-cov`
- **Инструменты:** Git, REST API (requests)
