# Веб-сервис анализа транзакций
## Описание проекта
Этот проект представляет собой веб-сервис для анализа финансовых транзакций. Он предоставляет следующие функции:

Главная страница: отображает приветствие, информацию по картам, курс валют и цены акций.
Простой поиск: поиск транзакций по описанию или категории.
Поиск по телефонным номерам: извлечение транзакций, содержащих мобильные номера.
Отчеты: генерация отчетов о расходах по категориям.
Анализ кешбэка: расчет выгодных категорий для повышенного кешбэка.

## Структура проекта
```
project/
│── src/
│   ├── __init__.py
│   ├── main.py          # Основной файл веб-приложения (Flask)
│   ├── views.py         # Обработчики страниц и API-запросов
│   ├── reports.py       # Функции формирования отчетов
│   ├── services.py      # Сервисный слой (анализ данных, поиск)
│   ├── utils.py         # Вспомогательные функции
│── data/
│   ├── operations.xlsx  # Данные о транзакциях
│── tests/
│   ├── __init__.py
│   ├── test_views.py
│   ├── test_reports.py
│   ├── test_services.py
│── user_settings.json   # Файл пользовательских настроек
│── .env                 # Файл с переменными окружения
│── .gitignore           # Игнорируемые файлы для Git
│── requirements.txt     # Список зависимостей
│── README.md            # Документация проекта
```

## Установка и запуск
1. Установка зависимостей
Создайте виртуальное окружение и установите зависимости:
```
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
venv\Scripts\activate     # Для Windows
pip install -r requirements.txt
```
