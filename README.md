# Finance-widget — виджет банковских операций

Учебный проект: backend-приложение на Flask для работы с банковскими транзакциями.
Предоставляет данные для веб-морды личного кабинета — главную страницу с виджетами,
поиск по транзакциям и по телефонным номерам в описании операций, а также отчёт
по расходам за выбранную категорию.

## Статус проекта

🚧 Ранняя стадия разработки. На данный момент реализован только слой маршрутов
(`src/main.py`) — он подключает функции из модулей `views`, `services`, `reports`,
`utils`, но сами эти модули и тесты к ним пока пустые и требуют реализации.

## Требования

- Python 3.13+
- [Poetry](https://python-poetry.org/) для управления зависимостями

## Установка

```bash
git clone https://github.com/Nesterov-art/cousre_job.git
cd cousre_job
poetry install
```

## Запуск

```bash
poetry run python src/main.py
```

Приложение поднимется в режиме отладки на `http://127.0.0.1:5000`.

## API

| Метод | Эндпоинт | Параметры | Описание |
|---|---|---|---|
| GET | `/main` | `date` | Главная страница — сводка по дате |
| GET | `/search` | `q` | Поиск транзакций по запросу |
| GET | `/search_phone` | — | Поиск транзакций с телефонными номерами в описании |
| GET | `/category_report` | `category` | Отчёт по расходам в заданной категории |
